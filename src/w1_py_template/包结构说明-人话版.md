## 二、逐个解释

### ① `__init__.py` —— 门面（最重要）

```python
from w1_py_template.core import add, sum_all
from w1_py_template.io.jsonio import dump_json, load_json

__all__ = ["add", "dump_json", "load_json", "sum_all"]
```

**人话**：它决定**别人 `import` 你这个包时能拿到什么**。

> 一个文件夹**加了 `__init__.py` 才算"包"**，不然只是普通目录。

`__all__` = **对外公开清单**：

| 写法 | 别人怎么用 | 效果 |
|---|---|---|
| 在 `__all__` 里 | `from w1_py_template import add` | ✅ 能拿到 |
| 不在 `__all__` 里 | `from w1_py_template import logger` | ❌ 拿不到 |

**Java 类比**：`__all__` ≈ 你的 `public` 方法列表。
Python 默认**什么都是公开的**（没有 `private` 关键字），所以你得**主动声明**哪些算对外 API——**这就是工程师意识。**

> ⚠️ 实测坑：ruff 的 **RUF022** 要求 `__all__` **按字母排序**。
> 按字母写，别按你脑子里想的逻辑顺序写。

---

### ② `core.py` —— 干活的代码（26 行）

```python
logger = logging.getLogger(__name__)  # ① 只 getLogger，绝不 basicConfig


def add(a: int, b: int) -> int:
    logger.debug("add %s + %s", a, b)  # ② 用 %s 占位符，不用 f-string
    return a + b
```

两条纪律：

| # | 规矩 | 为什么 |
|---|---|---|
| ① | **库代码只 `getLogger`，不 `basicConfig`** | `basicConfig` 是**应用入口**的事。库里调它 = 重复注册 handler → **日志翻倍或丢失**（和 SLF4J"库只依赖门面"完全同构） |
| ② | **日志用 `%s` 占位符，不用 f-string** | f-string **无论什么级别都会先拼字符串**（白费 CPU）；`%s` 是"确定要打印时才拼" |

---

### ③ `py.typed` —— 一张声明贴纸

**0 字节的空文件。** 唯一作用：**告诉 mypy"我这个包自带类型标注，你可以检查我"**。

没有它，别人装上你的包，mypy 会**跳过检查**（当成没类型的老代码）。

> **Java 类比**：≈ `module-info.java` 里声明"我导出了这些 API"。
> **文件是空的，作用全在"它在那儿"这件事本身。**

---

### ④ `io/` —— 子包（包里再分包）

```
io/
├── __init__.py      ← 每个子文件夹都要有，才算是"包"
└── jsonio.py        ← JSON 读写：dump_json / load_json
```

**每个想被 import 的文件夹，都得放一个 `__init__.py`。** 这是 Java 里不用操心、Python 里必须手写的东西。

`jsonio.py` 里两个函数，后面做 AI 项目时 **prompt 模板、评测结果落地**都靠它。

## 三、导入链条（谁依赖谁）

```
tests/test_core.py
        │  from w1_py_template import add, sum_all
        ▼
src/w1_py_template/__init__.py          ← 门面（唯一对外出口）
        │
        ├──→ core.py        (add / sum_all)
        └──→ io/jsonio.py   (dump_json / load_json)
```

**`tests/` 只认门面，不直接摸 `core.py`。** 这就是"公开 API 意识"：

> 以后你随便改 `core.py` 内部实现，只要门面不变，**测试一行都不用动**。
> Java 类比：测试只依赖 `interface`，不依赖 `impl`。

---

## 四、三条纪律（照抄）

1. **用 `src/` 布局** —— 强制先安装自己的包才能测，避免"当前目录隐式进 `sys.path`"的假绿
2. **`__init__.py` 里写 `__all__`** —— 明确导出 = Java 的"公开 API 意识"
3. **绝对不要**在代码里 `sys.path.append(...)`

## 五、一句话收口

> **`__init__.py` 是门面（决定对外暴露什么），`core.py` 是干活的地方，`io/` 是分类存放的子包，`py.typed` 是一张"我有类型标注"的声明贴纸。**
>
> **四样加起来不到 100 行——这就是一个正经 Python 包的全部骨架。**
